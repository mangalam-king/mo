# Built-in MO Olympiad Question Library

The Online Exam Manager includes a built-in mixed-subject library for Classes 3 to 9. Each class contains 100 multiple-choice questions covering age-appropriate mathematics, science, English, reasoning and general knowledge.

## Use it
1. Sign in to the main admin page with the authorized admin account.
2. Open `exam-admin.html`.
3. Create/select the exam and choose the appropriate class in **Built-in question bank class**.
4. Click **Load selected class bank (100 questions)**.
5. Enter student registration ID(s), select the exam, then enable the exam for the intended students.

The selected questions are copied into the question JSON field so the admin can review or edit them before assignment. The answer key is stored separately by the existing exam manager workflow.

Question banks are practice/olympiad-style mixed questions, not an official syllabus-aligned paper. Review the bank before assigning it.
